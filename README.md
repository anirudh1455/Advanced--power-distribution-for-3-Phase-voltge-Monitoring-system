# Advanced 3-Phase Power Distribution & Voltage Monitoring System

## 📌 About
A real-time 3-phase power distribution and voltage monitoring system 
built using the STM32 microcontroller. Designed to detect voltage 
imbalances and trigger alerts across all three phases.

## 🛠 Tech Stack
- STM32 Microcontroller
- Embedded C
- STM32CubeIDE
- HAL Library

## ⚙️ Features
- Real-time voltage monitoring across 3 phases
- Alert mechanism for voltage imbalance
- Low power consumption design

## 🚀 How to Run
1. Open project in STM32CubeIDE
2. Connect STM32 board via USB
3. Build and flash the `.ld` file to the board
4. Monitor output via serial console
